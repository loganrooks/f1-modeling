# Reviews Workspace

This initiative now uses the shared repo-level advisory review guidance in `.planning/reviews/README.md`.

Use this directory for initiative-specific advisory reviews and review-gate artifacts, including:

- wave review checklists and decisions
- advisory cross-model critique
- restructuring notes when the planned initiative shape changes

Do not use this directory for formal acceptance or application audits. Those belong in `../audit/` and should follow the shared package under `.planning/audits/`.

Initiative-specific note:

- a review here may recommend a narrow formal audit when a wave is about to certify repo-level planning or governance changes
- a review here does not itself satisfy formal audit preflight
