# Wave 4 Review Gate: GSDR Subsystem Adaptation Decisions

Use this gate after Wave `4A` is written and before any `4B` application wave is drafted or launched.

The gate exists to decide:

1. which remaining GSDR-specific subsystem lanes are application-worthy now
2. which should remain doctrine/governance only
3. whether the proposed `4B` still reads as one coherent harness follow-through

Required review questions:

- Did `4A` preserve Stage `3` as accepted input rather than reopening steering or routing work?
- Which lanes are truly application-worthy now, and which should stay doctrine-only for this initiative?
- Does the proposed `4B` scope stay narrow enough to avoid policy sprawl?
- Are audit, signal, and initiative-carry-forward proposals concrete enough to matter without redesigning those subsystems wholesale?
- Should `verify/validate`, signal automation, audit format redesign, or `3.2` proving-ground work stay explicitly out of scope after this gate?
