# Wave 5 Review Gate: Enforcement Decisions

Use this gate after Wave `5A` is written and before any `5B` application wave is drafted or launched.

The gate exists to decide:

1. whether Stage `5` still has one narrow remaining enforcement patch worth applying now
2. whether the current harness is already strong enough to move to the `3.2` proving-ground application

Required review questions:

- Which candidate enforcement lanes are already sufficiently landed through Stages `3` and `4`?
- Is there one narrow `5B` with real leverage, or would more enforcement now be governance bulk?
- What evidence is missing that only the `3.2` proving ground can provide?
- Should the initiative close Stage `5` without application and route to Stage `6`?
