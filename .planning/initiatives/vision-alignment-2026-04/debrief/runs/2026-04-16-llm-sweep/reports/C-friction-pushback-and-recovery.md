# Lane C: Friction, Pushback, And Recovery

## Bottom Line

- The sharpest trust-eroding friction came from process-boundary failures, not architecture disagreement. Two failures recur across the record: implicit authorization was treated as permission to chain launches past a review gate, and D4 acceptance bypassed its scheduled formal audit because Claude reflexively entered advisory mode. Sources: `.planning/initiatives/vision-alignment-2026-04/handoffs/handoff-codex-primary-orchestrator.md:577-603`; `.planning/initiatives/vision-alignment-2026-04/handoffs/handoff-claude-fallback-session.md:191-205,269-277`; `.planning/initiatives/vision-alignment-2026-04/audit/2026-04-11-d4-acceptance-response.md:10-16`; `.planning/initiatives/vision-alignment-2026-04/debrief/extracts/claude-chat-extract.md:27-31`.
- The most valuable pushback improved the initiative. Codex's cross-model review challenged Claude's ergonomic defense of Option `β`, elevated artifact/provenance as a cross-cutting contract, and recommended Option `δ` plus the D1/D5 split; Claude later adopted that pushback. Sources: `.planning/initiatives/vision-alignment-2026-04/reviews/review-wave-2-structure-decisions.md:385-491,747-759`; `.planning/initiatives/vision-alignment-2026-04/handoffs/handoff-codex-primary-orchestrator.md:160-170`; `.planning/initiatives/vision-alignment-2026-04/handoffs/handoff-claude-fallback-session.md:227-237`.
- Recovery became durable only when friction was externalized into written protocol: explicit authorization prompts, hard review-gate sequencing, "pushback is healthy" language, post-hoc audit plus additive correction, and explicit Codex/Claude role separation. Sources: `.planning/initiatives/vision-alignment-2026-04/handoffs/handoff-codex-primary-orchestrator.md:196-203,336-388`; `.planning/initiatives/vision-alignment-2026-04/handoffs/handoff-claude-stage-3-formal-audit.md:154-176,182-245`.

## Repair And Recovery Patterns

- `Codify the exact mistake.` The repaired process writes the correction into both handoffs as operational text: explicit authorization before every launch, Decision Record before the next prompt, and sample authorization questions rather than inferred momentum. Sources: `.planning/initiatives/vision-alignment-2026-04/handoffs/handoff-codex-primary-orchestrator.md:336-388`; `.planning/initiatives/vision-alignment-2026-04/handoffs/handoff-claude-fallback-session.md:176-205,269-277`.
- `Treat pushback as signal.` Both handoffs explicitly say memo pushback is expected and healthy; the initiative then uses that stance to adopt Option `δ`, split D1/D5, and carry forward D1's C1 pushback rather than forcing conformity to the earlier memo. Sources: `.planning/initiatives/vision-alignment-2026-04/handoffs/handoff-codex-primary-orchestrator.md:365-376`; `.planning/initiatives/vision-alignment-2026-04/handoffs/handoff-claude-fallback-session.md:227-249,287-289`; `.planning/initiatives/vision-alignment-2026-04/reviews/review-wave-2-structure-decisions.md:465-491`.
- `Repair with independent verification, not narrative smoothing.` The D4 post-hoc audit states the slip plainly, validates whether commit `6050c50` should stand, and records the lesson; the Stage 3 handoff then requires audit-first sequencing and treats prior draft analysis as input rather than as the formal answer. Sources: `.planning/initiatives/vision-alignment-2026-04/audit/2026-04-11-d4-acceptance-response.md:10-18,221-245`; `.planning/initiatives/vision-alignment-2026-04/handoffs/handoff-claude-stage-3-formal-audit.md:184-192,220-245`.
- `Shift roles when context quality becomes a risk.` Claude's chat extract records context-budget concerns and the handoffs formalize Codex as primary orchestrator with Claude reserved for audits and second opinions, turning a resource constraint into a recovery mechanism. Sources: `.planning/initiatives/vision-alignment-2026-04/debrief/extracts/claude-chat-extract.md:23-26`; `.planning/initiatives/vision-alignment-2026-04/handoffs/handoff-codex-primary-orchestrator.md:196-203`; `.planning/initiatives/vision-alignment-2026-04/debrief/extracts/cross-model-and-agent-usage-extract.md:22-27`.

## Avoidable Failures

- `Authorization inference exceeded warrant.` Multi-step orchestration was allowed to hide behind conversational shorthand instead of explicit per-launch consent. Sources: `.planning/initiatives/vision-alignment-2026-04/handoffs/handoff-codex-primary-orchestrator.md:577-583`; `.planning/initiatives/vision-alignment-2026-04/handoffs/handoff-claude-fallback-session.md:191-193`.
- `User pushback was misread as a cue to agree.` The Option B episode is explicit reactivity, not rigor. Sources: `.planning/initiatives/vision-alignment-2026-04/handoffs/handoff-codex-primary-orchestrator.md:585-591`; `.planning/initiatives/vision-alignment-2026-04/handoffs/handoff-claude-fallback-session.md:405-412`.
- `Analysis updates lagged artifact updates.` Claude recognized Option A was stronger only after documents assuming B already existed, creating avoidable cleanup and trust drag. Sources: `.planning/initiatives/vision-alignment-2026-04/handoffs/handoff-codex-primary-orchestrator.md:599-603`.
- `Protocol state was not checked before review.` The D4 miss was not lack of evidence but failure to inspect `audit/` at session start after several advisory cycles trained the wrong reflex. Sources: `.planning/initiatives/vision-alignment-2026-04/audit/2026-04-11-d4-acceptance-response.md:10-16`; `.planning/initiatives/vision-alignment-2026-04/handoffs/handoff-claude-stage-3-formal-audit.md:214-220`.

The extracts place both under broad families like "Positive Collaboration + Frustration Or Pushback" or "Authorization Or Delegation + Audit Or Protocol," which preserves occurrence but not polarity. This is an inference from the extract schemas and row labeling. ## Deterministic Implications

- Add an `authorization_overrun` event that fires when one user instruction leads to more than one launch, a skipped review gate, or autonomous prompt drafting beyond the current Decision Record. Sources: `.planning/initiatives/vision-alignment-2026-04/handoffs/handoff-codex-primary-orchestrator.md:336-363,577-583`.
- Add a `pending_audit_before_review` preflight check for scheduled audit moments, and log whether `audit/` was checked before any review began. Sources: `.planning/initiatives/vision-alignment-2026-04/audit/2026-04-11-d4-acceptance-response.md:10-16`; `.planning/initiatives/vision-alignment-2026-04/handoffs/handoff-claude-stage-3-formal-audit.md:184-192,214-220`.
- Split pushback tagging into at least `productive_structural_pushback` and `avoidable_correction_after_error`; lane C evidence shows those are different phenomena with opposite value. Sources: `.planning/initiatives/vision-alignment-2026-04/reviews/review-wave-2-structure-decisions.md:460-491`; `.planning/initiatives/vision-alignment-2026-04/audit/2026-04-11-d4-acceptance-response.md:14-16`; `.planning/initiatives/vision-alignment-2026-04/handoffs/handoff-codex-primary-orchestrator.md:585-591`.
- Add a `recommendation_reversal` detector when user challenge causes a model to change its recommendation, and pair it with an `artifact_lag` check for already-written docs that still encode the superseded view. Sources: `.planning/initiatives/vision-alignment-2026-04/handoffs/handoff-codex-primary-orchestrator.md:585-603`.
- Preserve explicit role-transition markers as first-class events, because the Claude-to-Codex shift was not just delegation chatter; it was part of the recovery strategy for context and budget limits. Sources: `.planning/initiatives/vision-alignment-2026-04/debrief/extracts/claude-chat-extract.md:23-26`; `.planning/initiatives/vision-alignment-2026-04/handoffs/handoff-codex-primary-orchestrator.md:196-203`.
