    **stintModel/tireModel.ts** -- Implement four pure functions:

    1. `initializeTireState(compound: TireCompoundParams, ambientTemp: number): TireState` -- Creates initial tire state: wearFraction 0, surfaceTemperature = ambientTemp, coreTemperature = ambientTemp, lapsSinceNew 0.

    2. `tireWearGripFactor(state: TireState, compound: TireCompoundParams): number` -- Linear degradation before cliff: `1.0 - 0.15 * wearFraction`. After cliffThreshold: quadratic cliff `preCliffGrip * (1.0 - cliffSeverity * cliffProgress^2)` where cliffProgress = (wear - threshold) / (1 - threshold). Floor at 0.3 to prevent solver collapse per RESEARCH.md Pitfall 3.

    3. `tireThermalFactor(state: TireState, compound: TireCompoundParams): number` -- Parabolic window: 1.0 inside [optimalTempLow, optimalTempHigh]. Outside: `1.0 - thermalSensitivity * deviation`. Floor at 0.5. Use surfaceTemperature.

    4. `updateTireState(prev: TireState, lapResult: LapModelOutput, compound: TireCompoundParams, envState: EnvironmentState): TireState` -- Per-lap update:
       - New wear: `prev.wearFraction + compound.baseWearRate * (1 + compound.wearAcceleration * prev.wearFraction)`. Clamp to [0, 1].
       - Surface temperature: moves toward an equilibrium temperature derived from average lap speed and track temperature. Use `compound.warmupRate` as the fraction of gap closed per lap: `prevTemp + warmupRate * (equilibriumTemp - prevTemp)`. Equilibrium = max(envState.trackTemperatureC, compound.optimalTempLow + 5) as engineering estimate.
       - Core temperature: slower convergence toward surface temp: `prevCore + 0.3 * (newSurface - prevCore)`.
       - Clamp max per-lap grip change to 10% per RESEARCH.md Pitfall 1 -- this is enforced in the StintRunner when computing effective grip, not in tireModel directly.

    **stintModel/loadTransfer.ts** -- Implement:

    1. `computeLoadSensitivityFactor(lateralG: number, longitudinalG: number, params: LoadTransferParams): number` -- Follow RESEARCH.md Pattern 4 exactly: lateral load shift fraction from `|lateralG| * g * cogHeight / trackWidth`, capped at 0.9. Load sensitivity with exponent 0.85: `((1+s)^0.85 + max(0.01, 1-s)^0.85) / 2`. Return value < 1.0 when load transfer is significant.

    2. `computeAverageLoadFactor(speedProfile: SpeedProfilePoint[]): number` -- Computes the distance-weighted average load sensitivity factor across a full lap speed profile. This gives a single representative load factor for the lap. Import SpeedProfilePoint from "../lapModel/types.js".

    3. Export `DEFAULT_LOAD_TRANSFER_PARAMS`.

    1. `initializeStintState(config: StintConfig): StintState` -- Creates initial state: lapNumber 0, tireState from `initializeTireState(config.tireCompound, config.weatherTimeline[0].trackTemperatureC)` (use first timeline entry, with safe fallback to 25C if empty), electricalState with SoC at maxCapacity (use a default stub: SoC 4_000_000, maxCapacity 4_000_000, all counters 0), environmentState from first weather timeline entry (or defaults: trackTemperatureC 33, surfaceWetness 0, rubberEvolution 1.0, gripModifier 1.0), fuelMass from config.baseVehicle.mass * 0.04 (approximate fuel fraction).

    2. `resolveEffectiveVehicle(baseVehicle: VehicleParams, state: StintState, config: StintConfig): VehicleParams` -- Computes effective vehicle params for the current lap:
       - `gripCoefficient`: Start from `config.tireCompound.peakGrip`, multiply by `tireWearGripFactor(state.tireState, config.tireCompound)`, multiply by `tireThermalFactor(state.tireState, config.tireCompound)`, multiply by `state.environmentState.gripModifier`, multiply by average load sensitivity factor (use `DEFAULT_LOAD_TRANSFER_PARAMS` and compute from previous lap's average lateral/longitudinal G, or use 1.0 for first lap). Clamp total effective grip to minimum 0.4 per RESEARCH.md Pitfall 3. Enforce max 10% change from previous lap's effective grip per RESEARCH.md Pitfall 1.
       - `peakPower`: baseVehicle.peakPower (stub -- Plan 02 adds electrical deployment power here).
       - `dragFactor`: baseVehicle.dragFactor (stub -- Plan 02 adds aero mode here).
       - `downforceFactor`: baseVehicle.downforceFactor (stub -- Plan 02 adds aero mode here).
       - `mass`: baseVehicle.mass - (initial fuel - remaining fuel) to account for fuel burn. Use approximate fuel consumption of 1.5 kg/lap (engineering estimate). Clamp minimum mass to baseVehicle.mass * 0.95.

    3. `runStint(config: StintConfig): StintResult` -- The main loop:

         b. Call `solveLap(config.circuit, effectiveVehicle)` (import from "../lapModel/lapSolver.js").
         c. Update tire state via `updateTireState()`.
         d. Update electrical state: identity for now (return prev state unchanged). Leave a clearly marked `// Phase 3 Plan 02: replace with updateElectricalState()` comment.
         e. Update environment state: identity for now. Leave a clearly marked `// Phase 3 Plan 03: replace with updateEnvironmentState()` comment.
         f. Update fuel state: subtract 1.5 kg, clamp >= 0.
         g. Build LapTrace with current lap's data.
       - Return StintResult with all lap traces, final state, total time (sum of lap times), and assumptions array.
       - Assumptions should include: "Lap-wise discretization (TUMFTM race-simulation validated)", "Phenomenological tire model (engineering-inference, not calibrated)", "Fuel consumption 1.5 kg/lap (engineering estimate)", "Load transfer 2-axle model (Milliken & Milliken)".
