    **stintModel/environmentModel.ts** -- Implement weather evolution and environment coupling. Import types from "./types.js".

    1. `interpolateWeatherAtLap(timeline: WeatherTimeline, lap: number): { trackTemperatureC: number; surfaceWetness: number }` -- Linear interpolation between timeline events. For a lap between two events, interpolate both trackTemperatureC and surfaceWetness linearly. Before the first event, use the first event values. After the last event, use the last event values. This implements RESEARCH.md Pitfall 4 mitigation: if rain starts at lap 5.5, lap 5 gets partial rain effect.

    2. `surfaceGripFactor(surfaceWetness: number): number` -- Maps wetness (0.0 = dry, 1.0 = standing water) to a grip multiplier. Dry = 1.0, light wet = 0.8, heavy wet = 0.55. Use a piecewise linear function: `1.0 - 0.45 * surfaceWetness` for wetness 0-1. Floor at 0.55.

    3. `rubberEvolutionFactor(lapNumber: number, surfaceWetness: number, prevRubber: number): number` -- Track rubber builds up over laps improving grip. Starts at 0.95 (green track) and asymptotes toward 1.05 (fully rubbered). Per-lap increment: `0.005 * (1.05 - prevRubber) / 0.10` (diminishing returns). Rain washes rubber away: if surfaceWetness > 0.3, rubber resets partially toward 0.95: `prevRubber - 0.3 * surfaceWetness * (prevRubber - 0.95)`. Clamp to [0.90, 1.05].

    4. `initializeEnvironmentState(timeline: WeatherTimeline): EnvironmentState` -- Creates initial state from the first timeline event (or defaults: trackTemperatureC 33, surfaceWetness 0, rubberEvolution 0.95). Compute gripModifier as `surfaceGripFactor(surfaceWetness) * rubberEvolution`.

    5. `updateEnvironmentState(prev: EnvironmentState, lapNumber: number, timeline: WeatherTimeline): EnvironmentState` -- Per-lap update:
       - Interpolate weather at current lap number to get trackTemperatureC and surfaceWetness.
       - Compute new rubber evolution from `rubberEvolutionFactor(lapNumber, surfaceWetness, prev.rubberEvolution)`.
       - Compute gripModifier as `surfaceGripFactor(surfaceWetness) * rubberEvolution`.
       - Return new EnvironmentState.
