## Vision Impact

This plan implements the async lifecycle that VISION.md § Visualization Vision requires for live-updating strategy views, and that LONG-ARC § Protected Seams 1 (transport-neutral execution boundary) embodies. Concretely:

- Submit / get / cancel / subscribe / fetch — the surface that lets a thin client over Tailscale stay responsive while a long-running race simulation completes asynchronously on dionysus.
- Replay-safe reconnect — late-joining clients (or the same client after a network blip) see the same job state as a continuous watcher. This is a long-arc honesty obligation, not a nice-to-have.
- The route shapes here are also the consumption surface for puzzle/skill-practice mode later: a "puzzle session" is a job that submits a masked-context simulation and emits scored judgment artifacts. The contracts must accommodate this without renaming.

The structured `disposition: preserved_seam` annotations in this plan's frontmatter mark each route as serving a specific seam, not as ad-hoc REST design.

## Honesty Surface

- Progress and partial-artifact events MUST NOT imply calibrated or higher-fidelity results. Each event's fidelity tier stays at the kernel's stated tier (per CONTEXT.md `<guardrails>` 2 and 5).
- Reconnect semantics: a client that watches live and a client that joins late must see the same final artifact set. Honesty is not time-dependent.
- Error envelopes propagate raw backend errors (sanitized only for security-sensitive paths, not for "looks nicer"). The consumer is the user; they need the real failure.

## Performance Budget

Thin-client baseline reference: developer on apollo (MacBook Air over Tailscale) hitting dionysus dev server. Constraints:

- Submit / get / cancel paths should not increase round-trip count vs. the existing synchronous run-create path for the same workload, except where SSE reconnect demands it (one extra catch-up call).
- Per-event payload size: prefer artifact references over inline payloads for any artifact > 64 KB (the threshold matters for keeping the SSE stream interactive over Tailscale).
- No durable benchmark harness exists yet — Phase 3.3 § Plan 05 builds it. For 3.2, the obligation is to **not regress** measured-by-hand against the current synchronous baseline. Plan SUMMARY should record observed round-trip count + smoke-test latency against `apps/local-api/src/__tests__/raceRuns.test.ts` as the comparable workload.

   - `GET /api/artifacts/:artifactId`
