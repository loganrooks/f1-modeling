**2. [Rule 1 - Bug] exactOptionalPropertyTypes compliance**
- **Found during:** Task 2
- **Issue:** TypeScript strict mode with exactOptionalPropertyTypes requires optional interface fields to explicitly include `| undefined`. Zod `.optional()` produces `T | undefined` which doesn't match `T?` without `| undefined` under this flag.
- **Fix:** Added `| undefined` to all optional fields in CreateRaceSimulationRunInput, TireUsageEntryInput, and TireUsageEntry interfaces.
- **Files modified:** apps/local-api/src/services/runService.ts, packages/sim-core/src/raceModel/tireInventory.ts
