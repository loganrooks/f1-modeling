**Create `packages/sim-core/src/__tests__/pitModel.test.ts`:**

Test the pit-lane loss model and interruption effects:

1. **computePitLoss tests:**
   - Default params produce a total loss in the 18-25s range
   - traversalDelta = (pitEntryTime + pitExitTime) - pitBypassTime
   - totalLoss = traversalDelta + serviceTime (no discount)
   - With discount factor 0.65 (VSC): totalLoss is 65% of green-flag loss
   - With discount factor 0.40 (SC): totalLoss is 40% of green-flag loss
   - With discount factor 0.0 (red flag): totalLoss is 0
   - Custom params: different pit configurations produce expected results

2. **interruptionLapTimeFactor tests:**
   - "vsc" returns 1.30
   - "sc" returns 1.40
   - "red-flag" returns Infinity

3. **pitLossDiscountFactor tests:**
   - "vsc" returns 0.65
   - "sc" returns 0.40
   - "red-flag" returns 0.0

4. **applyInterruptionsToLapTimes tests:**
   - No interruptions: output equals input (identity)
   - VSC from lap 5-8 (race-level) with raceStartLap 3: only stint-local laps 2-5 modified
   - SC from lap 10-12: affected laps are 40% slower
   - Red flag: affected laps set to 0
   - Interruption outside stint range: no modification
   - Multiple interruptions: each applied independently
   - Output is a new array (input not mutated)

   - Valid plan with tireInventory.used from prior sessions

2. **trackTireUsage tests:**
   - 3-stint race produces 3 usage entries
   - Each entry has correct compound, session, and stintIndex
   - Session string propagates correctly

**Create `packages/sim-core/src/__tests__/raceModel.test.ts`:**

Integration tests for the race engine, using real circuit data (Monza) and tire compound presets:

1. **Basic 2-stint race:**
   - 10 laps soft, 10 laps hard on Monza
   - Returns RaceResult with 2 stintResults, each with correct number of lapTraces
   - Timeline has exactly: 1 stint-start, 1 stint-end, 1 pit-event, 1 stint-start, 1 stint-end (5 events minimum)
   - totalRaceTime > 0 and equals sum of stint times + pit time
   - totalPitTime approximately equals expected pit loss (~20s)

2. **State continuity at pit boundary:**
   - Run 2-stint race
   - Verify: stint 2 starts with fresh tires (wearFraction ~0, new compound)
   - Verify: stint 2 electrical state carries over (SoC matches stint 1 final SoC)
   - Verify: stint 2 environment state carries over (trackTemperature matches)
   - Verify: stint 2 fuel state carries over (fuelMass matches, no refueling)

3. **3-stint race with compound variety:**
   - 15 laps soft, 20 laps medium, 15 laps hard
   - Timeline has 2 pit events
   - totalPitTime approximately 2x single pit loss
   - All stintSummaries have correct compound IDs

4. **Race with VSC interruption:**
   - 2-stint race (10+10 laps) with VSC at laps 5-7
   - Laps 5-7 in stint 1 should be ~30% slower than non-interrupted laps
   - Timeline contains interruption-start and interruption-end events
   - totalRaceTime is greater than a race without interruption

5. **Race with SC interruption overlapping pit stop:**
   - 2-stint race with SC at laps 9-12, pit after stint 1 (lap 10)
   - Pit loss should be discounted (factor 0.40)
   - totalPitTime should be approximately 40% of green-flag pit loss

6. **Race with red flag:**
   - 2-stint race with red flag at laps 8-10
   - Affected laps produce 0 time (session stopped)
   - If pit occurs during red flag, pit cost is 0

7. **Timeline event ordering:**
   - Events are in non-decreasing raceLap order
   - No duplicate events at the same position
   - All stintIndex values are sequential (0, 1, 2...)

8. **Plausible lap times:**
   - All lap times > 50s (Monza is ~80-90s)
   - No NaN or Infinity in any result field
   - totalRaceTime is plausible for the number of laps (within 2x of lapCount * expectedLapTime)

9. **runStintFromState backward compatibility:**
   - Run same config through runStint() and through runStintFromState(config, initializeStintState(config))
   - Results should be identical (same totalTime, same lapTraces)
