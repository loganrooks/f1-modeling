**Create `packages/sim-core/src/raceModel/tireInventory.ts`:**

1. **DEFAULT_TIRE_ALLOCATION** -- Standard 2024-2025 allocation (configurable per regulation preset):
   ```typescript
   export const DEFAULT_TIRE_ALLOCATION: TireSetAllocation[] = [
     { compound: "hard", totalSets: 2 },
     { compound: "medium", totalSets: 3 },
     { compound: "soft", totalSets: 8 },
   ];
   ```
   Add provenance comment: "FIA Sporting Regulations 2024-2025. 13 sets per standard weekend (2H/3M/8S). 2026 allocation TBD -- use as configurable default."

2. **TireSetAllocation** interface (import from raceModel/types or define locally):
   ```typescript
   interface TireSetAllocation {
     compound: string; // matches CompoundId but string for flexibility
     totalSets: number;
   }
   ```

3. **TireUsageEntry** interface:
   ```typescript
   interface TireUsageEntry {
     compound: string;
     session: string;
     stintIndex?: number;
   }
   ```

4. **validateTireInventory(stints: StintSpec[], allocation: TireSetAllocation[], priorUsage?: TireUsageEntry[]): { valid: boolean; errors: string[] }**
   - Count how many sets of each compound the race plan uses (each stint = 1 set of its compound).
   - Add any prior usage from qualifying or other sessions (priorUsage).
   - For each compound, check: usedSets <= totalSets in allocation.
   - Also validate the mandatory two-compound rule: a dry race must use at least two different dry compounds across all stints. (Skip this check if any stint uses "intermediate" or "wet" -- wet races have different rules.)
   - Return `{ valid: true, errors: [] }` if all checks pass.
   - Return `{ valid: false, errors: ["Soft tire allocation exceeded: used 9 of 8 available sets", ...] }` if any check fails.
   - This is a PRE-EXECUTION validation. The race engine should not run if inventory validation fails.

5. **trackTireUsage(stints: StintSpec[], session: string): TireUsageEntry[]**
   - Produces an array of TireUsageEntry objects from a completed race's stint list.
   - Each stint produces one entry: `{ compound: stint.tireCompound.compoundId, session, stintIndex: stint.stintIndex }`.
   - This is used after execution to update the tire inventory ledger for subsequent sessions.

**Modify barrel exports** in `raceModel/index.ts` and `sim-core/index.ts`:
Export `validateTireInventory`, `trackTireUsage`, `DEFAULT_TIRE_ALLOCATION`.

**Modify `apps/local-api/src/services/runService.ts`:**

Add `createRaceSimulationRun()` function following the same pattern as `createStintModelRun()`:

1. **Function signature:** `async createRaceSimulationRun(paths: LocalApiPaths, input: CreateRaceSimulationRunInput): Promise<Readonly<RunRecord>>`
   where `CreateRaceSimulationRunInput = { scenarioId: string; experimentTag?: string; parentRunId?: string; branchPoint?: { stintIndex: number; raceLap: number; branchType: "stint-boundary" } }`.

2. **Load scenario and presets** -- identical pattern to createStintModelRun.

3. **Validate racePlan exists** on the scenario. If `scenario.racePlan` is undefined, throw `RunDependencyError("Scenario does not contain a racePlan. Use stint-model for single-stint simulation.")`.

4. **Load circuit** -- identical pattern.

5. **Resolve each stint** from racePlan.stints:
   - For each stintSpec in racePlan.stints, load the tire compound preset via `loadTireCompoundPreset()`.
   - Resolve the electrical policy via `resolveElectricalPolicy()`.
   - Build a `StintSpec` (sim-core type) with resolved compound params and policy.

6. **Validate tire inventory** if `racePlan.tireInventory` is present:
   - Call `validateTireInventory(resolvedStints, racePlan.tireInventory.allocation, racePlan.tireInventory.used)`.
   - If validation fails, throw `RunDependencyError("Tire inventory validation failed: " + errors.join("; "))`.

7. **Build RaceConfig** from scenario + presets:
   - circuit, baseVehicle (scenario.vehicleParams ?? DEFAULT_VEHICLE_PARAMS)
   - weatherTimeline from weather preset (reuse extractWeatherTimeline)
   - aeroConfig from regulation preset (reuse the existing aeroConfig resolution logic from createStintModelRun -- extract to a shared helper if needed)
   - loadTransferParams: DEFAULT_LOAD_TRANSFER_PARAMS
   - pitLaneParams: from racePlan.pitLaneParams
   - ambientTemperatureC: from weather preset

8. **Resolve interruptions** from `racePlan.interruptions` (map domain InterruptionSpec to sim-core InterruptionSpec).

9. **Call `runRace(resolvedStints, raceConfig, interruptions)`** to get the RaceResult.

10. **Build run record** using `createRunRecord()`:
    - modelVersion: "race-simulation/v1"
    - summaryMetrics: harnessId "race-simulation", circuitId, vehicleParams, stintCount, totalRaceLaps, totalRaceTime, totalPitTime, stintSummaries, assumptions
    - artifacts: Per-stint artifacts (stint-trace, tire-degradation-trace, electrical-state-trace, weather-evolution-trace for each stint, with artifactId prefixed by stint index) PLUS a race-level timeline artifact:
      ```
      {
        artifactId: `${runId}-race-timeline`,
        artifactType: "race-timeline",
        label: "Race timeline with events and stint summaries",
        data: {
          timeline: raceResult.timeline,
          stintSummaries: raceResult.stintSummaries,
          totalRaceTime: raceResult.totalRaceTime,
          totalPitTime: raceResult.totalPitTime,
        },
      }
      ```
    - Pass through lineage fields: `parentRunId: input.parentRunId`, `branchPoint: input.branchPoint`, `experimentTag: input.experimentTag` (only if provided).
    - assumptionNotes: from raceResult.assumptions with RACE_MODEL_PROVENANCE.

11. **Persist and return** -- writeJsonFile + return runRecord.
