  <action>
Create `packages/domain/src/scenario/raceSchema.ts` with all race-related Zod schemas:

1. **stintSpecSchema** -- Per-stint specification within a race plan:
   - `stintIndex`: z.number().int().nonnegative() -- position in race
   - `totalLaps`: z.number().int().positive() -- laps in this stint
   - `tireCompoundId`: documentIdSchema -- compound for this stint
   - `electricalPolicyId`: z.string().optional() -- policy override (defaults to scenario-level)
   - Use `.strict()` consistent with all domain schemas.

2. **interruptionSpecSchema** -- User-authored race interruption:
   - `type`: z.enum(["vsc", "sc", "red-flag"])
   - `startLap`: z.number().int().nonnegative() -- race-level lap number
   - `endLap`: z.number().int().positive() -- race-level lap number (must be > startLap)
   - Add `.refine()` to enforce endLap > startLap
   - Use `.strict()`.

3. **pitLaneParamsSchema** -- Circuit-specific pit-lane loss parameters:
   - `pitEntryTime`: z.number().positive() -- seconds to decelerate and traverse pit entry
   - `pitExitTime`: z.number().positive() -- seconds to accelerate and traverse pit exit
   - `pitBypassTime`: z.number().positive() -- seconds at racing speed over pit lane distance
   - `serviceTime`: z.number().nonnegative() -- stationary service time (default ~2.5s)
   - Use `.strict()`.

4. **tireSetAllocationSchema** -- Per-compound allocation:
   - `compound`: documentIdSchema
   - `totalSets`: z.number().int().positive()
   - Use `.strict()`.

5. **tireInventorySchema** -- Weekend tire inventory:
   - `allocation`: z.array(tireSetAllocationSchema).min(1)
   - `used`: z.array(z.object({ compound: documentIdSchema, session: z.string(), stintIndex: z.number().int().nonnegative().optional() }).strict())
   - Use `.strict()`.

6. **racePlanSchema** -- Complete race plan:
   - `stints`: z.array(stintSpecSchema).min(1) -- ordered stint specifications
   - `interruptions`: z.array(interruptionSpecSchema).optional() -- user-authored interruptions
   - `pitLaneParams`: pitLaneParamsSchema -- circuit-specific pit config
   - `tireInventory`: tireInventorySchema.optional() -- weekend tire tracking
   - `totalRaceLaps`: z.number().int().positive() -- total race distance for validation
   - Use `.strict()`.

7. **branchPointSchema** -- Fork metadata on run record:
   - `stintIndex`: z.number().int().nonnegative()
   - `raceLap`: z.number().int().nonnegative()
   - `branchType`: z.enum(["stint-boundary"]) -- starts with stint-boundary only; extensible to "mid-stint" later
   - Use `.strict()`.

Export all schemas and their inferred types.

  - `parentRunId: documentIdSchema.optional()` -- links to parent run for lineage

**In `packages/domain/src/runs/createRunRecord.ts`:**

**In `packages/domain/src/index.ts`:**

All new fields are `.optional()` to preserve backward compatibility with existing scenarios and run records. The existing `stintConfig` field remains -- a scenario uses either `stintConfig` (single stint) or `racePlan` (race), never both simultaneously (enforcement is at the application level, not schema level, matching Phase 3's approach).

Create the `packages/sim-core/src/raceModel/` directory and its type definitions.

**Create `packages/sim-core/src/raceModel/types.ts`:**

These are sim-core internal interfaces (no Zod), paralleling how `stintModel/types.ts` works.

1. **PitLaneParams** -- mirrors the domain schema but as a plain interface:
   - pitEntryTime: number
   - pitExitTime: number
   - pitBypassTime: number
   - serviceTime: number

2. **PitLossResult** -- output of pit-loss calculation:
   - totalLoss: number (total time lost vs staying on track)
   - traversalDelta: number (entry+exit minus bypass)
   - serviceTime: number

3. **InterruptionType** = "vsc" | "sc" | "red-flag"

4. **InterruptionSpec** -- input interruption event:
   - type: InterruptionType
   - startLap: number
   - endLap: number

5. **StintSpec** -- per-stint specification for race engine:
   - stintIndex: number
   - totalLaps: number
   - tireCompound: TireCompoundParams (resolved, not ID)
   - electricalPolicy: ElectricalPolicy (resolved)

6. **RaceConfig** -- full race engine configuration:
   - circuit: CircuitDocument
   - baseVehicle: VehicleParams
   - weatherTimeline: WeatherTimeline
   - aeroConfig: AeroModeConfig | null
   - loadTransferParams: LoadTransferParams
   - pitLaneParams: PitLaneParams
   - ambientTemperatureC: number

7. **RaceTimelineEvent** -- discriminated union on `type`:
   - "stint-start": { stintIndex, raceLap, compound: CompoundId, policyId: string }
   - "stint-end": { stintIndex, raceLap, stintTime, cumulativeRaceTime, finalTireWear, finalSoC, effectiveGripRange: [number, number] }
   - "pit-event": { afterStintIndex, raceLap, pitLoss: PitLossResult, newCompound: CompoundId }
   - "interruption-start": { interruptionType: InterruptionType, raceLap }
   - "interruption-end": { interruptionType: InterruptionType, raceLap }
   Each variant includes `type` as the discriminant.

8. **RaceResult** -- output of runRace:
   - stintResults: StintResult[]
   - timeline: RaceTimelineEvent[]
   - totalRaceTime: number
   - totalPitTime: number
   - stintSummaries: Array<{ stintIndex, compound, laps, stintTime, finalWear, finalSoC }>
   - assumptions: string[]

Import types from `../stintModel/types.js` (CompoundId, TireCompoundParams, ElectricalPolicy, etc.) and from `@f1-modeling/domain` (CircuitDocument).
