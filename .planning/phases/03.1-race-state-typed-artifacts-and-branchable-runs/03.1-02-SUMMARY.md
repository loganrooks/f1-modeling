# Phase 3.1 Plan 02: Race-State Engine with Pit Model, Interruptions, and Typed Timeline Summary

**Multi-stint race engine orchestrating existing stint runner with pit-lane loss (L_pit formula), VSC/SC/red-flag interruption effects, and chronologically ordered typed timeline events**

## Accomplishments
- Implemented reduced-order pit-lane loss model: `computePitLoss()` using L_pit = (t_entry + t_exit - t_bypass) + t_stop with discount factor for safety conditions
- Created interruption effects model with lap-time multipliers (VSC: 1.3x, SC: 1.4x, red-flag: Infinity) and pit-cost discount factors (VSC: 0.65, SC: 0.4, red-flag: 0.0)
- Refactored stintRunner.ts: extracted core loop into shared `runStintLoop()` helper, added `runStintFromState()` for race engine multi-stint sequencing; `runStint()` behavior unchanged
- Built race engine `runRace()` that sequences stints, applies pit-event state mutations (fresh tires, SoC carry-through, no refueling), injects interruption effects, and produces typed timeline
- Timeline events are chronologically sorted with deterministic intra-lap ordering (interruption-start < stint-start < stint-end < pit-event < interruption-end)
- Comprehensive test suite with 129 new assertions covering pit model, interruption model, 2-stint race, 3-stint race, state continuity, interruption injection, and pit-under-VSC discount
