**Friction ellipse module (packages/sim-core/src/lapModel/frictionEllipse.ts):**

Implement three pure functions based on Lenzo & Rossi 2020 Eq. 3-9:

1. `computeCorneringSpeedLimit(curvature: number, vehicle: VehicleParams): number`
   - Takes absolute curvature (1/m) and vehicle params.
   - Solves the quadratic: `v_max = sqrt(mu * g / (curvature - mu * kz / m))`.
   - When `curvature <= mu * kz / m` (beyond critical radius), return `Infinity` (no grip-limited constraint).
   - When curvature is 0 or negative, return `Infinity`.
   - Use `const g = 9.81`.

2. `maxAcceleration(speed: number, curvature: number, vehicle: VehicleParams): number`
   - Compute lateral acceleration consumed: `ay = speed^2 * |curvature|`.
   - Compute max lateral capacity: `ayMax = mu * (g + kz * speed^2 / m)`.
   - Friction ellipse ratio: `ayRatio = min(ay / ayMax, 1)`.
   - Grip-limited longitudinal: `axGrip = mu * (g + kz*v^2/m) * sqrt(1 - ayRatio^2) - kx*v^2/m`. Note: drag reduces available forward force.
   - Power-limited: `axPower = speed > 0.1 ? (P - kx*v^3) / (m*v) : P / (m * 0.1)`.
   - Return `min(axGrip, axPower)`. Clamp to `max(result, 0)` to prevent negative acceleration during the forward pass.

3. `maxDeceleration(speed: number, curvature: number, vehicle: VehicleParams): number`
   - Same lateral fraction computation.
   - Braking force: `axBrake = mu * (g + kz*v^2/m) * sqrt(1 - ayRatio^2) + kx*v^2/m`. Drag assists braking.
   - Return the positive magnitude (deceleration).

**Forward-backward solver (packages/sim-core/src/lapModel/forwardBackward.ts):**

Implement the two-pass global envelope approach:

`solveSpeedProfile(circuit: CircuitLayoutPoint[], vehicle: VehicleParams): SpeedProfilePoint[]`

1. Compute cornering speed limit at every point using `computeCorneringSpeedLimit(|curvature|, vehicle)`.
2. **Forward pass:** Starting from `v[0] = min(corneringLimit[0], 1)` (nearly stationary start -- the loop nature is handled later), for each subsequent point: `v_accel = sqrt(max(0, v[i-1]^2 + 2 * ax * ds))` where `ax = maxAcceleration(v[i-1], |curvature[i-1]|, vehicle)` and `ds = distance[i] - distance[i-1]`. Set `v_forward[i] = min(v_accel, corneringLimit[i])`.
3. **Backward pass:** Starting from `v[n-1] = v_forward[n-1]`, iterate in reverse: `v_brake = sqrt(max(0, v[i+1]^2 + 2 * ax * ds))` where `ax = maxDeceleration(v[i+1], |curvature[i+1]|, vehicle)` and `ds = distance[i+1] - distance[i]`. Set `v_backward[i] = min(v_forward[i], v_brake)`.
4. **Lap closure:** After the backward pass, use `v_backward[0]` to re-run a second forward pass starting from `min(v_backward[0], corneringLimit[0])`, then a second backward pass ending at `v_forward[n-1]`. This ensures the speed at start/finish is consistent for a closed loop. If the difference between first and second pass is less than 0.1 m/s at all points, stop. Otherwise, do one more iteration (two iterations is sufficient for convergence in practice).
5. Build `SpeedProfilePoint[]` from the final speed array. For each point:
   - `regime`: If `speed >= corneringLimit * 0.99` then `"cornering"`. Else if `speed < v_forward * 0.99` then `"braking"`. Else compare power-limited vs grip-limited acceleration to determine `"accelerating-power"` or `"accelerating-grip"`.
   - `lateralG = speed^2 * |curvature| / 9.81`.
   - `longitudinalG`: Compute from speed difference between adjacent points: `(v[i]^2 - v[i-1]^2) / (2 * ds * 9.81)`. For i=0, use 0.
   - `timeIncrement = ds / ((v[i] + v[i-1]) / 2)` for i > 0, 0 for i = 0.

Use `Float64Array` for the speed arrays (performance for 1000+ point circuits).

**Lap solver orchestrator (packages/sim-core/src/lapModel/lapSolver.ts):**

`solveLap(circuit: CircuitDocument, vehicle: VehicleParams): LapModelOutput`

1. Extract `CircuitLayoutPoint[]` from the `CircuitDocument.points` array (just distance and curvature, dropping x/y).
2. Call `solveSpeedProfile(layoutPoints, vehicle)`.
3. Derive `SectorResult[]` from the speed profile and `circuit.sectors`: For each sector, filter speed profile points within `[startDistance, endDistance)`, sum their `timeIncrement` values to get `sectorTime`, find `minSpeed` and `maxSpeed`, determine `limitingFactor` from the dominant regime in that sector.
4. Compute total `lapTime = sum of all timeIncrement values`.
5. Build `assumptions` array with honest model notes: "Quasi-steady-state point-mass model (Lenzo & Rossi 2020)", "Constant grip coefficient (no tire degradation)", "No elevation effects", "No lateral force balance (Phase 2 longitudinal only)", "No aero-mode switching", "Vehicle parameter defaults are engineering-inference, not calibrated".
6. Return `{ lapTime, speedProfile, sectorResults, assumptions }`.
